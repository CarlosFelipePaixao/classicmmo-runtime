# ClassicMMO Runtime

ClassicMMO Runtime é um fork personalizado do EasyRPG Player para rodar projetos criados no RPG Maker 2003 com futuras funcionalidades online.

## Objetivo inicial

- Manter compatibilidade com projetos RPG Maker 2000/2003.
- Usar o RPG Maker 2003 como editor.
- Usar este runtime como player personalizado.
- Futuramente adicionar camada online com login, chat, jogadores remotos e sincronização de mapa.

## Estado atual

- EasyRPG Player compilado com sucesso no Windows.
- Projeto teste do RPG Maker 2003 rodando no Player.exe compilado localmente.
- Branch principal de desenvolvimento: classicmmo/dev.
